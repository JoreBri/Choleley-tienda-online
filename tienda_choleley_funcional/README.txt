PLANTILLA TIENDA FUNCIONAL CON ESTILO CHOLELEY

Incluye:
- index.html: página de inicio.
- productos.html: catálogo con filtros por categoría.
- carrito.html: carrito funcional.
- styles/stile.css: estilo visual basado en Choleley.
- js/productos.json: productos editables.
- js/main.js: carga productos, filtra categorías y agrega al carrito.
- js/carrito.js: muestra, elimina, vacía y compra productos del carrito.

IMPORTANTE:
1. Para modificar productos, editar js/productos.json.
2. Cada producto debe tener un id único.
3. El id de categoria debe coincidir con el id del botón de productos.html.
4. Las imágenes deben ubicarse en las carpetas img/ correspondientes o cambiar la ruta en productos.json.
5. Para probar fetch correctamente, abrir con Live Server.
